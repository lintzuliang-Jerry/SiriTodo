# SiriTodo — 極速記

一個以語音輸入為核心、只保留必要功能的待辦清單 PWA。

## 為什麼做這個專案

市面上的待辦工具大多沒有順手的語音輸入，或加入了太多我用不到的功能。我真正需要的只是快速記下一件事、分好類，然後繼續做眼前的工作，所以做了 SiriTodo。

## 功能

- 中文語音新增待辦，依關鍵字自動分到「當天待辦」、「每日例行」或「長期待辦」
- 手動新增、編輯、刪除、勾選與拖曳排序
- 自訂語音分類關鍵字
- PWA 支援，可加入手機或桌面主畫面
- 待辦與設定保存在瀏覽器 `localStorage`
- Service Worker 快取靜態檔案，載入後可離線開啟

## 使用方式

這是純前端專案，不需要安裝套件。請用本機 HTTP 伺服器開啟：

```bash
python -m http.server 8000
```

接著前往 `http://localhost:8000`。按下畫面下方的麥克風即可開始語音輸入。

> 麥克風通常只允許在 `localhost` 或 HTTPS 網頁使用。語音辨識由瀏覽器的 Web Speech API 提供，是否需要連線、音訊如何處理，取決於使用的瀏覽器與平台。

## 資料與隱私

待辦內容與分類規則只存放在目前瀏覽器，不會由本專案上傳到伺服器。清除網站資料會一併刪除待辦，請自行留意。

## 技術

Vanilla JavaScript、HTML、CSS、Web Speech API、SortableJS、Service Worker。
